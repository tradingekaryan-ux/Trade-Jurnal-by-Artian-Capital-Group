# 03 — Daftar fitur (pemetaan dari library upstream)

Semua fitur berikut **diambil dari** [`LuxAlgo/trade-journal`](https://github.com/LuxAlgo/trade-journal) dan **dipertahankan**. Kolom "Perlakuan" menunjukkan perubahan yang dilakukan di proyek ini.

| Fitur                              | Penjelasan (dari upstream)                                                                                                                                                                                                                                                                                                         | Perlakuan di proyek ini                                                                                                        |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Sinkron broker (read-only)**     | `@luxalgo/broker-sdk`: Alpaca, Binance, Bybit, Coinbase, Kraken, OKX, Tradier, IBKR Flex, Hyperliquid, Questrade, Topstep, Trading212, Webull, Crypto.com, E*TRADE, Public, Charles Schwab, TradeStation, tastytrade, Robinhood Crypto, Gemini, KuCoin. Form koneksi dirender dari metadata SDK.                                   | Dipertahankan. Kredensial per pengguna, dienkripsi AES-256-GCM, tidak pernah dibagikan.                                        |
| **Import pernyataan (16+ format)** | TradeZella, Tradervue, TradingView (paper & strategy), MetaTrader 4/5, ThinkorSwim, IBKR (activity + Flex CSV/XML), NinjaTrader, Tradovate, TopstepX, Webull, DAS Trader, XTB, Hyperliquid, plus CSV column mapper. Deteksi otomatis, dedup per akun, tinjauan warning & baris dilewati.                                           | Dipertahankan penuh, termasuk sample & dokumentasi importer.                                                                   |
| **AI statement import**            | PDF/CSV/HTML/XML yang tidak dikenali diuraikan model AI menjadi execution untuk ditinjau.                                                                                                                                                                                                                                          | **Dimodifikasi:** penyedia diganti OpenRouter. Model wajib mendukung PDF + structured output; fallback pesan jelas bila tidak. |
| **Round-trip engine**              | Siklus flat-ke-flat dari fill; FIFO / LIFO / weighted-average per akun; partial fill, scale-in, flip, multiplier futures; anotasi bertahan saat rebuild.                                                                                                                                                                           | Dipertahankan apa adanya dari `@luxalgo/journal-core`.                                                                         |
| **Analitik mendalam**              | Net/gross P&L, win rate & day-win rate, profit factor, expectancy, R multiples, streak, drawdown & recovery, profit concentration, performa berdasarkan durasi/jam/hari/ simbol/tag/mistake/playbook. Filter lintas dimensi, grup perbandingan, matriks cross-analysis, rolling trends, trade explorer scatter, MAE/MFE tersimpan. | Dipertahankan; hasil selalu terbatas pada data pengguna yang login.                                                            |

| **Halaman trade**                  | Chart Vela dengan penanda entry/exit & label P&L, path fill, candle pilihan pengguna, replay, estimasi MAE/MFE, running P&L, execution, rating, stop/target, tag, mistake.                                                                                                                                                         | Dipertahankan; query diarahkan ke database pengguna yang login.                                                                |
| **Jurnal harian**                  | Statistik harian, kurva P&L intraday, catatan Markdown autosave dengan template & lampiran (gambar/PDF), diketik atau **didikte** lewat speech recognition browser.                                                                                                                                                                | Dipertahankan; voice note tetap tanpa kunci AI (memakai layanan speech browser).                                               |
| **Notebook & playbook**            | Folder, pencarian, tag, tautan ke trade; setup bernama dengan checklist aturan, skor kepatuhan per trade, analisis followed vs broken di Reports.                                                                                                                                                                                  | Dipertahankan.                                                                                                                 |

| **Demo data**                      | "Load demo data" (~90 hari trade sintetis) dan demo prop firm di memori browser.                                                                                                                                                                                                                                                   | Dipertahankan; data demo dibuat di bawah akun pengguna yang memuatnya.                                                         |
| **Migrasi TradeZella / Tradervue** | Alur impor + penjelasan batas rekonstruksi harga rata-rata.                                                                                                                                                                                                                                                                        | Dipertahankan.                                                                                                                 |
| **Light/dark theme & mobile**      | Tema, sidebar kolaps, layout responsif.                                                                                                                                                                                                                                                                                            | Dipertahankan; preferensi tersimpan per pengguna.                                                                              |

## Fitur baru yang ditambahkan proyek ini

| Fitur                 | Keterangan                                                                        |
| --------------------- | --------------------------------------------------------------------------------- |
| Registrasi akun       | Username + password, tanpa email/verifikasi.                                      |
| Login & logout        | Session berbasis cookie bertanda tangan, masa berlaku terbatas.                   |
| Isolasi data per akun | Satu file SQLite per pengguna + proxy database berbasis sesi.                     |
| Kuota & rate limit    | Membatasi percobaan login, registrasi, dan pemakaian AI agar tetap gratis & aman. |
| OpenRouter settings   | Pilihan model (dari daftar yang diizinkan) atau BYOK opsional.                    |

## Tidak ada fitur upstream yang dihapus

Keputusan desain: **tidak ada pengurangan fitur** demi kemudahan implementasi. Jika suatu fitur bergantung pada penyedia AI (AI import), maka fitur tersebut tetap ada dengan mengganti backend-nya ke OpenRouter.
